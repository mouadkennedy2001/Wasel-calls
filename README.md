# مكالمات واصل

تطبيق محادثة ومكالمات صوتية ومشاركة ملفات يعمل على **الشبكة المحلية (Wi-Fi / Ethernet)** بدون إنترنت.
واجهة على طراز **GNOME / Adwaita** مع 19 ثيمًا، وضع RTL افتراضي وعربي/إنجليزي.

## المميزات

- تسجيل دخول وإنشاء حساب **محلي** (اسم مستخدم + كلمة سر مشفّرة بـ PBKDF2-SHA256، وتُخزَّن البيانات مشفّرة عبر `safeStorage` على سطح المكتب). يعمل بدون إنترنت.
- بروفايل احترافي: صورة رمزية مقتطعة، اسم ظاهر، نبذة، حالة (متصل/بعيد/مشغول)، لون مميز، عرض بروفايل الآخرين.
- اكتشاف تلقائي للأجهزة عبر UDP Broadcast + اسم شبكة Wi-Fi/Ethernet + إدخال يدوي لعنوان IP.
- غرف محادثة (إنشاء/انضمام/خروج، غرف محمية بكلمة مرور، سجل رسائل محفوظ على المضيف).
- رسائل مباشرة بين المستخدمين + مؤشر كتابة + إشعارات غير مقروءة.
- مكالمات صوتية: **WebRTC mesh** للجودة، و**بديل UDP PCM** للتوافقية على سطح المكتب، مع وضع تلقائي.
- `micEV`: تحسين المايك محليًا (إلغاء صدى WebRTC، تقليل الضوضاء، AGC، مرشّحات HP/LP، ضاغط، بوابة صوت VAD، تحكم بالحساسية).
- مشاركة ملفات حتى 200MB مع تقدم الرفع، روابط تنزيل بصلاحية ساعة، وحماية من هجمات Path Traversal، ودعم كامل لأسماء الملفات غير اللاتينية (عربي/صيني/...) عبر ترميز ترويسات HTTP.
- 19 ثيمًا (Adwaita، Yaru، Nord، Dracula، Catppuccin، High Contrast، Fedora، Windows...) مع وضع تلقائي حسب النظام ولون مميز.
- أيقونات SVG مدمجة بدل الإيموجي، تصميم متجاوب للجوال، دعم Capacitor لإنتاج APK.

## التصميم والواجهة

- طبقتا تصميم نهائيتان: `polish.css` ثم `gnome.css` (تُحمّل أخيراً) لضبط الواجهة على طراز **GNOME / libadwaita**: أسطح صلبة مسطّحة، شريط عنوان بعنوان مركزي، شريط جانبي بلون مميز للقسم النشط، أزرار وحوارات ومساحات بنصف قطر 12px، وحالة تركّز واضحة.
- شريط صوت سفلي موصول فعلياً بـ `voice.render()` مع مستوى الميكروفون وأزرار الكتم/الدخول، ويبقى فوق شريط التنقل على الجوال.
- عرض المحادثة يملأ ارتفاع النافذة بالكامل: الرسائل تتوسّع، ومربع الكتابة مثبّت في الأسفل بلا مساحات فارغة.
- تخطيط متجاوب بالكامل: سطح مكتب ≥1500px، لابتوب 1024px، جهاز لوحي 820px، جوال 390px، جوال صغير 360px، ووضع أفقي 844×390 — دون أي تمرير أفقي.
- شريط تنقل سفلي على الجوال يتسع لكل الأقسام السبعة (بما فيها الشبكة والإعدادات)، وأهداف لمس لا تقل عن 38–44px.
- تغيير اللغة من الإعدادات يحدّث الشريط وعنوان النافذة وكل الأقسام فوراً؛ وشارات الرسائل غير المقروءة تظهر على قسم المحادثة.
- مكالمات DM تعمل عبر WebRTC بإشارة غرفة صحيحة (`dm:<peerId>`)، ورفض المكالمات الواردة تلقائياً عند الانشغال، وتبديل وضع الصوت لا يُعيد تشغيل مكالمة جارية.
- مؤشر «يكتب الآن» يختفي تلقائياً، ومسودة الرسالة تبقى محفوظة عند تحديث الواجهة أو انضمام عضو جديد.
- عناوين IPv6 تعمل في رابط WebSocket وروابط الملفات (`ws://[::1]:7788/ws`)، وتبديل المضيف يدوياً لا يُنشئ حلقة إعادة اتصال.
- إعداد «تصغير إلى شريط النظام» يُقرأ وقت الإغلاق، فيسري فوراً بدون إعادة تشغيل، ونافذة Electron تُستعاد من الشريط بدل تشغيل خادم جديد.
- اختصارات لوحة المفاتيح: `Ctrl/Cmd+K` للبحث في الغرف، و`Ctrl/Cmd+1..7` للتنقل بين الأقسام، و`Esc` لإغلاق النوافذ، و`Enter` لتأكيد الحوار.
- احترام تفضيل النظام `prefers-reduced-motion`، ودعم RTL/LTR كامل.
- اللغة الافتراضية عند التشغيل الأول تُكتشف من لغة النظام (عربي أو إنجليزي) وتُحفظ للمرات التالية؛ الثيم الافتراضي `Adwaita Dark` مع بقاء خيار «تلقائي» متاحاً.
- من «الإعدادات → نسخ الإعدادات احتياطياً» يمكن تصدير الإعدادات إلى ملف JSON واستيرادها على جهاز آخر.

## التشغيل السريع

```bash
npm install
npm start                 # سيرفر LAN على المنفذ 7788
npm run dev               # تطبيق Electron (يبدأ السيرفر داخليًا)
npm run check             # فحص الملفات والصياغة
npm test                  # اختبارات الوحدة
```

افتح من جهاز آخر على نفس الشبكة: `http://<IP-الجهاز-المضيف>:7788`

### المنافذ الافتراضية
| المنفذ | الاستخدام |
|---|---|
| 7788 | HTTP + WebSocket (`/ws`) + رفع/تنزيل الملفات |
| 7789 | اكتشاف UDP Broadcast |
| 7790 | ترحيل صوت UDP (اختياري) |

يمكن تغيير المنفذ 7788 عبر `WASEL_PORT=8000 npm start`، أو إدخال عنوان مضيف يدويًا من واجهة «الشبكة».

### بناء مثبّت Windows

```bash
npx electron-builder --win --x64 --publish never
```

يُنتج `dist/مكالمات واصل Setup 1.0.0.exe` ونسخة غير مثبّتة في `dist/win-unpacked/`. في الشبكات المقيدة استخدم المرآة:

```powershell
$env:ELECTRON_MIRROR='https://registry.npmmirror.com/-/binary/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://registry.npmmirror.com/-/binary/electron-builder/'
npx electron-builder --win --x64 --publish never
```

## نسخة الجوال (APK)

```bash
npm install
npm run build:mobile      # نسخ الويب إلى android/ عبر Capacitor
npm run apk               # يتطلب Android SDK، ينتج APK debug
```

أو افتح مجلد `android/` في Android Studio وابنِ APK. التفاصيل في [docs/ANDROID.md](docs/ANDROID.md).
على الجوال لا توجد مقابس UDP في WebView؛ لذلك يعتمد الاكتشاف على عنوان المضيف اليدوي + معلومات Wi-Fi من بلجن `WaselDiscovery`، والصوت يعبر WebRTC.

## البنية

```
src/main/      سيرفر Node، Electron main/preload، اكتشاف UDP، تخزين محلي، ترحيل صوت UDP
src/shared/    ثوابت وتحقق من المدخلات (تُستخدم في Node والمتصفح)
src/renderer/  واجهة HTML/CSS/JS وحديثة (ES modules) + AudioWorklets
android/       مشروع Capacitor الأندرويد
scripts/       أدوات البناء والأيقونات والفحص
tests/         اختبارات الوحدة
```

## الأمان

- `contextIsolation` و`sandbox` مفعّلان في Electron، و`nodeIntegration` معطّل، ولا يتسرب `ipcRenderer` للواجهة.
- CSP صارم، منع التنقل الخارجي، فتح الروابط عبر قائمة مسموح بها http/https فقط.
- تحقق من كل رسائل WebSocket (النوع، الطول، المعرّف، المخطط) + تحديد معدل الطلبات + heartbeat.
- تنظيف أسماء الملفات، حجم أقصى 200MB، تنزيل كـ `application/octet-stream` مع `nosniff` وصلاحية محدودة.
- كلمات المرور لا تُحفظ plaintext؛ المقارنة بـ `timingSafeEqual`، والبيانات مشفّرة على Electron.
- حدود صارفة لعدد المستخدمين/الغرف/الأعضاء/الصوت لمنع إنهاك الذاكرة.

## استكشاف الأخطاء
- إذا فشل تنزيل ثنائي Electron أثناء `npm install` (شبكة مقيدة)، شغّل `node node_modules/electron/install.js` أو استخدم مرآة:
  `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`
- إذا لم يظهر الأجهزة تلقائياً، افتح «الشبكة» وأدخل IP المضيف يدوياً (مثل `10.0.0.5:7788`).
- اسم SSID يظهر من Windows عبر `netsh wlan show interfaces` ومن Linux عبر `iwgetid` أو `nmcli`.

## ملاحظة عن mic_ev

لم أجد حزمة npm معروفة باسم `mic_ev`، لذلك تم تنفيذ وحدة محلية باسم `micEV` في `src/renderer/js/micEV.js` تستخدم قيود WebRTC الصوتية الأصلية وسلسلة Web Audio DSP، دون أي اعتماد خارجي أو إرسال للصوت لأي خدمة.
