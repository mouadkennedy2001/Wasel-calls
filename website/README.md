# موقع واصل كولز الثابت

موقع تسويقي/تحميل ثابت بالكامل (HTML + CSS + JavaScript فقط، بلا بناء أو حزم خارجية)، بواجهة مستوحاة من **GNOME / libadwaita**.

## الملفات

```
website/
├── index.html               # سبع sections: البداية، المميزات، المنصات، الإصدارات، الدليل، الأسئلة، الخاتمة
├── assets/css/style.css     # تصميم Adwaita داكن/فاتح، متجاوب من 360px إلى 1500px+
├── assets/js/app.js         # جلب GitHub API، أحدث مستقر، عدّادات، ثيم، تنقّل، نسخ البصمة
├── assets/favicon.svg       # أيقونة SVG مدمجة
└── .nojekyll                # توافق مع GitHub Pages
```

## المميزات

- **أحدث إصدار مستقر تلقائياً:** يجلب `GET /repos/mouadkennedy2001/Wasel-calls/releases`، يستبعد المسودات والإصدارات التجريبية، ويقارن أرقام الإصدارات (semver) لتثبيت الأحدث في الأعلى. زر التحميل يشير مباشرة إلى ملف APK الصحيح.
- **الإصدارات السابقة:** كل الإصدارات والملفات داخل قائمة قابلة للطي، مع التاريخ وعدد التحميلات وبصمة SHA256 القابلة للنسخ.
- **عدادات حية:** النجوم، التحميلات، عدد الإصدارات والمنصات — مع حركة عدّ خفيفة تحترم `prefers-reduced-motion`.
- **حالة الاتصال:** شريط صغير يخبرك إن كانت البيانات محدثة من GitHub أو مخزنة مؤقتاً أو احتياطية.
- **عمل دون اتصال:** بيانات احتياطية مدمجة + تخزين مؤقت في `localStorage` لمدة 10 دقائق. لا توجد أي خدمة خارجية سوى GitHub API.
- **المظهر:** داكن / فاتح / تلقائي حسب النظام، محفوظ في المتصفح.
- **تجاوب كامل:** 360px، 390px، 820px، 1024px، 1500px+، مع RTL ولوحة مفاتيح وقارئات شاشة.
- **أمان المحتوى:** كل بيانات GitHub تُهرَّب قبل الإدراج في DOM، والروابط المقبولة من GitHub فقط.

## المعاينة محلياً

```bash
cd website
python -m http.server 8080
# افتح http://localhost:8080
```

أو افتح `index.html` مباشرة؛ عندها ستظهر البيانات الاحتياطية إن منع المتصفح طلبات API من `file://`.

## النشر على GitHub Pages

الملفات موجودة داخل المجلد `website/` على الفرع `main`. لتفعيل Pages من الواجهة:

1. افتح **Settings → Pages**.
2. اختر **Source: Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/website`.
4. احفظ. سيصبح الموقع متاحاً على `https://mouadkennedy2001.github.io/Wasel-calls/`.

> ملاحظة: حدود GitHub API غير المصادَق عليها هي 60 طلباً في الساعة لكل عنوان IP. يستخدم الموقع تخزيناً مؤقتاً لتقليل الطلبات.
