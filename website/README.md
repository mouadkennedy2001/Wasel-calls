# موقع واصل كولز الثابت

موقع ثابت بالكامل (HTML + CSS + JavaScript + خطوط محلية، بلا أدوات بناء أو حزم خارجية)، بواجهة مستوحاة من **GNOME / libadwaita**، وثنائي اللغة **العربية / English**.

## الملفات

```
website/
├── index.html                  # 7 أقسام + ترجمة ثنائية عبر data-en / data-en-html
├── manifest.webmanifest        # تطبيق ويب (PWA) يستخدم icon.svg
├── icon.svg                    # أيقونة التطبيق والموقع (من تصميم المستخدم)
├── assets/css/style.css        # تصميم Adwaita، RTL/LTR، خطوط محلية
├── assets/js/app.js            # جلب GitHub، لغات، ثيم، بحث، عدّادات، نسخ
├── assets/fonts/               # IBM Plex Sans Arabic + Inter (woff2 + تراخيص OFL)
└── .nojekyll                   # توافق مع GitHub Pages
```

## المميزات

- **ثنائي اللغة كامل:** زر `AR / EN` في الشريط العلوي يبدّل كل النصوص والعناوين والـ meta والتاريخ والأرقام واتجاه الصفحة (RTL/LTR)، ويحفظ الاختيار في `localStorage`.
- **خطوط محلية:** `IBM Plex Sans Arabic` للعربية و`Inter` للإنجليزية، محمّلتان من ملفات `woff2` داخل المشروع — لا حاجة للإنترنت لعرض الخطوط. التراخيص في `assets/fonts/`.
- **أيقونة واحدة:** `icon.svg` مستخدم كـ favicon، و.apple-touch-icon، وأيقونة manifest، وشعار التطبيق داخل الواجهة المصغّرة، وبطاقة المُصنّع في التذييل.
- **أحدث إصدار مستقر تلقائياً:** يجلب `GET /repos/mouadkennedy2001/Wasel-calls/releases`، يستبعد المسودات والتجريبية، ويقارن semver لتثبيت الأحدث في الأعلى مع رابط APK الصحيح وبصمة SHA256.
- **بحث في الإصدارات:** حقل بحث يصفّي الإصدارات السابقة بالاسم أو الملاحظات أو اسم الملف.
- **عدادات حية:** النجوم، التحميلات، الإصدارات، المنصات — مع حركة عدّ تحترم `prefers-reduced-motion`، وإعادة تنسيق الأرقام عند تغيير اللغة.
- **حالة المزامنة:** يخبرك إن كانت البيانات محدثة من GitHub أو مخزنة مؤقتاً أو احتياطية.
- **عمل دون اتصال:** بيانات احتياطية مدمجة + تخزين مؤقت 10 دقائق.
- **المظهر:** داكن / فاتح / تلقائي حسب النظام، محفوظ في المتصفح.
- **تجربة استخدام:** شريط تقدم القراءة، إبراز القسم النشط، زر العودة للأعلى، نسخ الأوامر والروابط والبصمة، قوائم جوال، وتخطيط متجاوب من 360px إلى 1500px+.
- **الإسناد:** «صُنع بواسطة zerouki ahmed mouad — زروقي أحمد معاذ» في التذييل وبيانات `schema.org` المنظمة.
- **أمان المحتوى:** كل بيانات GitHub تُهرَّب قبل الإدراج في DOM، والروابط المقبولة من `github.com` فقط.

## المعاينة محلياً

```bash
cd website
python -m http.server 8080
# افتح http://localhost:8080
```

## النشر على GitHub Pages

1. افتح **Settings → Pages**.
2. اختر **Source: Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/website`.
4. احفظ. الموقع: `https://mouadkennedy2001.github.io/Wasel-calls/`.

> حدود GitHub API غير المصادَق عليها: 60 طلباً/ساعة/IP. يستخدم الموقع تخزيناً مؤقتاً لتقليل الطلبات.
